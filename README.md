# Sonic Garden Camp 開発課題

## URL
- 開発環境: [localhost:3000](http://localhost:3000/)
- サインアップ: [http://localhost:3000/users/sign_up](http://localhost:3000/users/sign_up)
- お題への回答: [http://localhost:3000/themes/1/posts](http://localhost:3000/themes/1/posts)

## アプリ起動まで
1. リポジトリのクローン
2. `rails db:migrate`
3. `rails db:seed`
4. `bin/dev` でサーバー起動

## 実装機能
- 開発基礎課題
- ニックネーム付き投稿
- Deviseによるユーザ登録、ログイン機能
- 自分の投稿の編集、削除機能
- Bootstrapによるスタイルの適用
